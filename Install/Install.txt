Установка и настройка Entware Manager
=====================================

1. Подготовка окружения
-----------------------

Перед установкой убедитесь, что в системе установлены необходимые пакеты:

opkg update
opkg install lighttpd ttyd htop jq coreutils-base procps-ng bridge-utils ip-full

- lighttpd – веб-сервер
- ttyd – для веб-терминала и монитора процессов
- htop – интерактивный монитор процессов
- jq – для работы с JSON
- coreutils-base – базовые системные утилиты
- procps-ng – утилиты процессов (pgrep, ps)
- bridge-utils – для отображения мостов (brctl) на вкладке статистики
- ip-full – расширенный ip (маршруты, интерфейсы)

После установки перезапустите lighttpd:

/opt/etc/init.d/S80lighttpd restart


2. Размещение файлов
--------------------

Все файлы проекта должны быть скопированы в каталог /opt/temp/web_entware.
Если у вас есть архив с файлами, распакуйте его:

tar -xzf entware-manager.tar.gz -C /opt/temp/

Убедитесь, что в /opt/temp/web_entware присутствуют:
- index.html, style.css, icons.svg
- entware.js, modal.js, monitor.js, network.js
- watchdog.sh, network_watchdog.sh, service_watchdog.sh, backup.sh
- подкаталоги: cgi-bin/, lib/, menu/, logger/, doc/, Install/
- cgi-bin/ содержит: *.cgi, monitor/, logger/, network/, service_watchdog/
- doc/ — полная документация (CHANGELOG.md, INSTALL.md, API.md и др.)


3. Запуск установки
-------------------

Выполните скрипт установки (он создаст /opt/web_entware и скопирует файлы):

chmod +x /opt/temp/web_entware/Install/install.sh
/opt/temp/web_entware/Install/install.sh

Скрипт сам скопирует файлы, установит правильные права и перезапустит lighttpd.


4. Настройка lighttpd
---------------------

Убедитесь, что в конфигурации /opt/etc/lighttpd/lighttpd.conf есть алиасы для
/entware-manager/ и /entware-cgi/. Пример:

alias.url = (
    "/entware-manager/" => "/opt/web_entware/",
    "/entware-cgi/" => "/opt/web_entware/cgi-bin/"
)

Также должен быть включён модуль mod_alias (для alias.url) и mod_cgi. Если их нет,
добавьте в server.modules:

server.modules += ( "mod_alias", "mod_cgi" )

Затем перезапустите lighttpd:

/opt/etc/init.d/S80lighttpd restart

Проверьте, что lighttpd запущен:

pgrep -f lighttpd


5. Проверка работы
------------------

Откройте в браузере: http://<IP_роутера>:8087/entware-manager/
(замените IP на адрес вашего роутера).
Должна открыться главная страница Entware Manager.


6. Настройка планировщика (cron) для ротации логов
--------------------------------------------------

Добавьте задачу в файл /opt/etc/crontab:

0 12 * * * /opt/web_entware/logger/scripts/rotate.sh >> /opt/tmp/log_rotate.log 2>&1

Если вы используете системный crontab, выполните:

echo "0 12 * * * /opt/web_entware/logger/scripts/rotate.sh >> /opt/tmp/log_rotate.log 2>&1" | crontab -


7. Запуск демона защиты (опционально)
-------------------------------------

Если вы планируете использовать модуль защиты от зависших процессов, запустите демон:

/opt/web_entware/watchdog.sh >> /opt/temp/logs/monitor.log 2>&1 &

Для автоматического запуска после перезагрузки добавьте эту строку в /opt/etc/rc.local
(до exit 0):

/opt/web_entware/watchdog.sh >> /opt/temp/logs/monitor.log 2>&1 &


8. Запуск демона сети (опционально)
-----------------------------------

Модуль мониторинга сети отслеживает состояние интерфейсов и перезапускает их при
потере связи. Запустите демон:

/opt/web_entware/network_watchdog.sh >> /opt/temp/logs/network_watchdog.log 2>&1 &

Для автозапуска добавьте в /opt/etc/rc.local:

/opt/web_entware/network_watchdog.sh >> /opt/temp/logs/network_watchdog.log 2>&1 &


9. Запуск демона служб (опционально)
------------------------------------

Модуль отслеживания служб перезапускает упавшие службы из списка. Запустите демон:

/opt/web_entware/service_watchdog.sh >> /opt/temp/logs/service_watchdog.log 2>&1 &

Для автозапуска добавьте в /opt/etc/rc.local:

/opt/web_entware/service_watchdog.sh >> /opt/temp/logs/service_watchdog.log 2>&1 &


10. Запуск ttyd (для вкладок «Процессы» и «Терминал»)
------------------------------------------------------

Для работы вкладок нужны два экземпляра ttyd:

- htop на порту 8089:
  ttyd -p 8089 -W htop &

- Терминал на порту 9089 (с паролем admin):
  ttyd -p 9089 -W -c admin:ВАШ_ПАРОЛЬ --permit-any-origin /opt/bin/bash &
  (Если bash отсутствует, замените на /bin/sh.)

Для автозапуска добавьте эти команды в /opt/etc/rc.local.


11. Резервное копирование
-------------------------

Встроенный скрипт /opt/web_entware/backup.sh создаёт полную копию интерфейса и конфигураций.
Запустите его вручную или добавьте в crontab:

0 3 * * * /opt/web_entware/backup.sh >> /opt/tmp/backup.log 2>&1

Резервные копии сохраняются в /opt/temp/backup/EntwareManager_backup_YYYYMMDD_HHMMSS/.


12. Устранение неполадок
------------------------

- Проверьте логи lighttpd: /opt/var/log/lighttpd/error.log
- Логи действий менеджера: /tmp/entware/logs/ и /opt/var/log/entware/
- Лог демона защиты: /opt/temp/logs/monitor.log
- Лог демона сети: /opt/temp/logs/network_watchdog.log
- Лог демона служб: /opt/temp/logs/service_watchdog.log
- Убедитесь, что все CGI-скрипты исполняемы:
  find /opt/web_entware/cgi-bin -type f -name "*.cgi" -exec chmod 755 {} \;
- Убедитесь, что подкаталоги cgi-bin доступны:
  find /opt/web_entware/cgi-bin -type d -exec chmod 755 {} \;
- Если страница не открывается, проверьте порт lighttpd (по умолчанию 8087).
  Изменить порт можно в /opt/etc/lighttpd/lighttpd.conf (параметр server.port).
- Если не отображаются сетевые данные — проверьте установку bridge-utils и ip-full.


13. Обновление
--------------

Для обновления достаточно скопировать новые файлы поверх существующих и выполнить
шаги 3–4 (повторно запустить `/opt/temp/web_entware/Install/install.sh` и перезапустить lighttpd).
Конфигурации (links.json, monitor_config.json, network_config.json) при этом сохранятся.

Принудительно обновите страницу в браузере после обновления (Ctrl+F5)
из-за кеширования JS/CSS.


После выполнения всех шагов Entware Manager полностью готов к использованию.
При возникновении проблем обратитесь к документации или проверьте логи.
